# teme/contracts

The interfaces, hooks and value classes that TemeCMS plugins and themes are built against. Every public type and method carries `@since`, the Teme version that introduced it.

This repository is a read-only copy of `packages/teme-contracts` in [temecms/teme](https://github.com/temecms/teme), made on every change. Open issues and pull requests there.

```bash
composer require teme/contracts
```

The developer handbook: https://github.com/temecms/teme/tree/main/docs/guides/developers
