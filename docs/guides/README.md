# Teme's guides

Two guides, one for each kind of reader:

- **[The operators' guide](operators/README.md)**, for the person who runs a Teme site's server: installing it, configuring it, putting it behind HTTPS and a platform, updating it, backing it up and restoring it, and the runbook for moving a WordPress site onto Teme.
- **[The editors' guide](editors/README.md)**, for the people who write, review and look after the site's content: signing in, writing, publishing, the lists, media, comments, settings and backups, in the words the admin uses.

Both are tested against the code they describe (`docs/architecture/documentation.md`), so what they say is what the release does.
