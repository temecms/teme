# The editors' guide

This guide is for the people who write, review and look after a site's content: contributors, authors, editors and administrators. It tells you how to do each job, in the words the admin uses.

It does not cover running the server. When a page says "whoever runs the server", that is the person to tell.

## What you can do

Your role decides what the admin lets you do. Find your role across the top.

| What you can do | Contributor | Author | Editor | Administrator |
|---|---|---|---|---|
| Write and save your own drafts | Yes | Yes | Yes | Yes |
| Write and edit pages | No | No | Yes | Yes |
| Publish your own work | No | Yes | Yes | Yes |
| Edit work written by others | No | No | Yes | Yes |
| Delete any item | No | No | Yes | Yes |
| Upload media | No | Yes | Yes | Yes |
| Edit any media | No | No | Yes | Yes |
| Organise categories and tags | No | No | Yes | Yes |
| Manage menus | No | No | Yes | Yes |
| Moderate comments | No | No | Yes | Yes |
| Manage redirects | No | No | Yes | Yes |
| Clear the page cache | No | No | No | Yes |
| Change settings | No | No | No | Yes |
| Manage people | No | No | No | Yes |
| Manage backups | No | No | No | Yes |

A contributor writes a draft and sends it for review. Someone with more access publishes it.

Pages, such as About and Contact, are the site's structure, so editors and administrators write them. Contributors and authors write posts.

## Names in bold are the words on screen

When a page sets a name in bold, it is a word you will see on a button, a tab, a field or a chip, written as the screen writes it. `Settings › General` means the **Settings** screen, then its **General** page. Anything else that needs stress is in italics.

For every setting and its default, see the [settings reference](../../reference/settings.md).

## What this guide leaves out

Importing from another site, themes and plugins are an administrator's work and are not here yet.
