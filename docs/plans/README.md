# Plans

A plan is the step-by-step a builder follows to implement an accepted [proposal](../proposals/README.md): the files, the tests written first, the code that is delicate enough to spell out, and the checks to run.

One file per proposal, named like it: `docs/plans/<topic>.md`, with a link back to `docs/proposals/<topic>.md`. A plan is a working file. Once its work is merged and released it may be removed; the proposal keeps the reasons and [`docs/architecture/`](../architecture/) describes what was built.
