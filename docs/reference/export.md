# Export format reference

> Generated by `php artisan teme:docs:export` from the export’s kinds. **Do not edit** — a hand edit here is a bug in the generator.

**Every line** is one JSON object on one line, ending in `\n`, UTF-8. Its first two keys:
- `kind`: the file's kind, as named below.
- `version`: the kind's version: 1 for every kind in this release.

**Times** are UTC, `2026-10-20T14:03:07.123456Z`. **IDs** are as Teme stores them: items, terms, comments, menus, menu items, redirects and people's bylines as lowercase ULIDs; media as uppercase ULIDs; people as whole numbers. **Documents** (`document`, `body`) are Tiptap JSON as the editor stores it; an internal link's `href` is `teme:content/<item ID>`, and an image names its media by `mediaId`. **Fields** are each item's typed fields as stored, media and people by ID.

**The files are written in this order**, each before the files that refer to it, so an importer can read them in turn:
`people`, `bylines`, `terms`, `media`, `contents`, `comments`, `menus`, `menu_items`, `redirects`, `settings`.

## `people.ndjson`

Kind `people`, version 1. Every account, by ID.

| Key | What it holds |
|---|---|
| `id` | The person's ID. |
| `name` | Their name. |
| `email` | Their email address. |
| `slug` | The last part of their author page's address. |
| `bio` | Their biography, or null. |
| `roles` | Their roles' names, such as `editor`. |
| `state` | `active`, `invited` (they haven't accepted their invitation yet) or `suspended`. |
| `created_at` | When the account was made. |

## `bylines.ndjson`

Kind `bylines`, version 1. Every person a byline names, with an account or without, by ID. An item with no bylines credits its owner, `author_id` in `contents`.

| Key | What it holds |
|---|---|
| `id` | The person's ID, a lowercase ULID. |
| `account_id` | The ID of the account this person is, from `people`, or null. |
| `name` | Their name, as pages show it. |
| `slug` | The last part of their author page's address. |
| `bio` | Their biography, or null. |

## `terms.ndjson`

Kind `terms`, version 2. Every term of every taxonomy, by ID. A child may come before its parent.

| Key | What it holds |
|---|---|
| `id` | The term's ID. |
| `taxonomy` | Its taxonomy's key, such as `category` or `tag`. |
| `name` | Its name. |
| `slug` | The last part of its address. |
| `parent_id` | Its parent term, or null. |
| `language` | The language it is written in, as a BCP 47 tag; null for the site's default language. |
| `translation_group` | The same for every language version of one item (or term); null for one with no other version. |
| `description` | Its description, or null. |
| `fields` | Its fields, as an object. |
| `created_at` | When it was made. |
| `updated_at` | When it last changed. |

## `media.ndjson`

Kind `media`, version 1. Every media item not in the trash, by ID, each with its original copied into the export’s `media/` folder.

| Key | What it holds |
|---|---|
| `id` | The media item's ID. |
| `media_kind` | `image`, `video`, `audio` or `document`. |
| `mime_type` | Its type, such as `image/jpeg`. |
| `extension` | Its file extension, such as `jpg`. |
| `original_filename` | The file's name when it was uploaded. |
| `name` | Its name in the address of its files. |
| `title` | Its title. |
| `alt` | Its alternative text, or null. |
| `caption` | Its caption, or null. |
| `credit` | Who made it, or null. |
| `licence` | The licence it is used under, or null. |
| `width` | Its width in pixels, or null. |
| `height` | Its height in pixels, or null. |
| `animated` | Whether it is an animated image. |
| `focal_x` | Where its focal point lies across, as a percentage. |
| `focal_y` | Where its focal point lies down, as a percentage. |
| `size_bytes` | The original's size when it was uploaded. |
| `sha256` | The original's SHA-256 when it was uploaded. |
| `uploaded_by` | Who uploaded it, or null. |
| `created_at` | When it was uploaded. |
| `updated_at` | When its record last changed. |
| `file` | The original in this export, or null when it couldn't be read (its ID is then in the manifest's `media.missing`). |
| `file.path` | Its path inside the export, such as `media/01JB2ZQ8V3K7N4W5X6Y7Z8A9BC.jpg`. |
| `file.bytes` | Its size, as copied. |
| `file.sha256` | Its SHA-256, as copied. When it differs from `sha256`, the file has changed since it was uploaded, and its ID is in the manifest's `media.differs`. |

## `contents.ndjson`

Kind `contents`, version 2. Every item not in the trash, of every type (posts, pages, regions and any registered type), by ID.

| Key | What it holds |
|---|---|
| `id` | The item's ID. |
| `type` | Its content type's key, such as `post` or `page`. |
| `slug` | The last part of its address. |
| `status` | `draft`, `review`, `scheduled` or `published`. |
| `author_id` | The account it belongs to, or null. |
| `bylines` | The IDs of the people it credits, from `bylines`, in order. Empty when it credits its owner, `author_id`. |
| `published_at` | When it was first published, or null. |
| `scheduled_for` | When it is due to be published, or null. |
| `comment_status` | Whether readers may comment: `open`, `closed` or `hidden`. |
| `visibility` | Who may read it: `public`, `private` (only people signed in who may see it) or `protected` (readers who know its password; the export never carries the password). |
| `parent_id` | The item it sits under, of the same type, or null. A child may come before its parent. |
| `position` | Its place among its parent's children, lowest first, then by ID. |
| `language` | The language it is written in, as a BCP 47 tag; null for the site's default language. |
| `translation_group` | The same for every language version of one item (or term); null for one with no other version. |
| `created_at` | When it was made. |
| `updated_at` | When it last changed. |
| `published` | The revision readers see, or null if it has never been published. |
| `published.id` | That revision's ID. |
| `published.title` | Its title. |
| `published.excerpt` | Its excerpt, or null. |
| `published.document` | Its body, as Tiptap JSON. |
| `published.fields` | Its fields, as an object. |
| `published.terms` | The IDs of its terms, in the order they were chosen. |
| `published.author_id` | Who wrote this revision, or null. |
| `published.origin` | `human`, `ai` or `import`. |
| `published.created_at` | When this revision was saved. |
| `working` | The draft being edited, when it differs from the published revision; otherwise null. |
| `working.id` | That revision's ID. |
| `working.title` | Its title. |
| `working.excerpt` | Its excerpt, or null. |
| `working.document` | Its body, as Tiptap JSON. |
| `working.fields` | Its fields, as an object. |
| `working.terms` | The IDs of its terms, in the order they were chosen. |
| `working.author_id` | Who wrote this revision, or null. |
| `working.origin` | `human`, `ai` or `import`. |
| `working.created_at` | When this revision was saved. |
| `computed` | Values worked out when the export was made, never references. |
| `computed.address` | Its address on the site, relative to the site's own (such as `/2026/10/harbour-news/`), while readers can see it; otherwise null. |

## `comments.ndjson`

Kind `comments`, version 1. Every comment on an exported item, but spam, by ID.

| Key | What it holds |
|---|---|
| `id` | The comment's ID. |
| `content_id` | The item it is on. |
| `parent_id` | The comment it answers, or null. |
| `comment_kind` | `comment`, `pingback` or `trackback`. |
| `status` | `approved`, `pending`, `trash`, `removed` (a removed comment kept so its replies keep their place, with no words or author), or a status a plugin registered. |
| `author_name` | The commenter's name, or null. |
| `author_email` | The commenter's email address, or null. |
| `author_url` | The commenter's website, or null. |
| `author_user_id` | The person, when a signed-in person wrote it; otherwise null. |
| `body` | Its words, as Tiptap JSON, or null when removed. |
| `legacy_id` | Its number on the site it was imported from, or null. |
| `created_at` | When it was written. |
| `status_changed_at` | When its status last changed. |

## `menus.ndjson`

Kind `menus`, version 1. Every menu, by ID.

| Key | What it holds |
|---|---|
| `id` | The menu's ID. |
| `name` | Its name. |
| `handle` | The name themes ask for it by. |
| `created_at` | When it was made. |
| `updated_at` | When it last changed. |

## `menu_items.ndjson`

Kind `menu_items`, version 1. Every menu's links, by ID. A child may come before its parent; `position` orders siblings.

| Key | What it holds |
|---|---|
| `id` | The link's ID. |
| `menu_id` | The menu it belongs to. |
| `parent_id` | The link it sits under, or null. |
| `position` | Its place among its siblings, from 0. |
| `link_kind` | What it points to: `content` (an item), `term`, `home` or `url`. |
| `target_id` | The item's or term's ID, for `content` and `term`; otherwise null. |
| `url` | The address, for `url`; otherwise null. |
| `label` | Its words, or null to show the item's or term's own title. |
| `opens_new_tab` | Whether it opens in a new tab. |

## `redirects.ndjson`

Kind `redirects`, version 1. Every redirect, by ID.

| Key | What it holds |
|---|---|
| `id` | The redirect's ID. |
| `source` | The address it answers, relative to the site, without its first or last slash, such as `old-news`; a pattern's placeholders in square brackets, such as `news/[slug]`. |
| `match` | `exact`, or `pattern` when `source` holds placeholders. |
| `status` | The answer: 301, 302, 307 or 308 to send readers on; 410 (gone) or 451 (unavailable for legal reasons) to send them nowhere. |
| `target_kind` | Where it sends readers: `address` (on this site), `outside`, `content` (an item, wherever it is now) or `media`; null for 410 and 451. |
| `target` | The address, or the item's or media's ID; null for 410 and 451. |
| `enabled` | Whether it is switched on. |
| `note` | A note about it. |
| `origin` | `manual` or `import`. |
| `hits` | How many times readers have been sent on by it. |
| `last_hit_at` | When it last sent a reader, or null. |
| `created_by` | Who made it, or null. |
| `updated_by` | Who last changed it, or null. |
| `created_at` | When it was made. |
| `updated_at` | When it last changed. |

## `settings.ndjson`

Kind `settings`, version 1. Every settings group, in the order they are registered, with its values as the site reads them. Settings that are secrets are never included, nor the discussion settings’ hold and block lists.

| Key | What it holds |
|---|---|
| `group` | The group's key, such as `general`. |
| `values` | Its settings, key by key, as an object: each one's saved value, or its default. |

## Files plugins add

A plugin that declares `contributes.exports` adds one file for each, named `plugin_<code>_<id>.ndjson`, after the files above. It reads like any of them: each line starts with its `kind` and `version`, then the plugin's own keys. The manifest lists the file with the others, and its `plugin_kinds` gives the plugin's Composer name and the fields it documents. A plugin that fails is left out, and the manifest's `left_out` says so; the rest of the export is unharmed.

## `manifest.json`

Written last; an export folder without one is incomplete.

| Key | What it holds |
|---|---|
| `format` | `teme-export`. |
| `format_version` | 1. |
| `teme_version` | The Teme that wrote it, such as `0.1.0`. |
| `made_at` | When the export was made. |
| `made_from` | The site's address when it was made, for the record; nothing in the export depends on it. |
| `files` | Each NDJSON file, in the order written: its `kind`, `file`, `version`, `lines`, `bytes` and `sha256`. |
| `types_file` | The site's own content types, taxonomies and fields, with the permission grants of its own types, as `teme-types.json` (the file `teme:types:export` prints): its `file`, `bytes` and `sha256`. Import it first, with `teme:types:import`, so the items' types, taxonomies and fields are defined. |
| `media.folder` | `media`. |
| `media.files` | How many originals were copied. |
| `media.bytes` | Their size together. |
| `media.missing` | The IDs of media items whose original couldn't be read. |
| `media.differs` | The IDs of media items whose original has changed since it was uploaded. |
| `plugin_kinds` | The files plugins added, each with its `kind`, the Composer name of its `plugin`, its `description` and its `fields`, in the plugin's own words. A plugin's file is named `plugin_<code>_<id>.ndjson`. |
| `left_out` | What the export leaves out, and why: a list of `what` and `why`. |

## What the export leaves out

| What | Why |
|---|---|
| Passwords, two-factor secrets and recovery codes, remember-me and reset tokens | Secrets: an export is for taking your content elsewhere, and a secret that leaves the site is no longer one. |
| Settings that are secrets, such as AI providers’ keys and the backups’ machine key | The same: secrets never leave the site. |
| Commenters’ IP addresses and browsers | Kept on this site only for a while, to fight spam, and of no use anywhere else. |
| Comments marked as spam | Junk the site caught, as WordPress’s export leaves it out too. |
| The spam checks’ verdicts on comments, and the private tokens that let commenters edit their words | This site’s own checks, which mean nothing to another system. |
| Items and media in the trash, and comments on items in the trash | Someone removed them, and they are waiting to be deleted for good. |
| Earlier revisions, autosaves, reviews and scheduled publishing | An export carries what each item says now, and its draft; its history and its workflow belong to backups. |
| The image sizes made from each original | Any system that imports the originals makes its own. |
| People’s interface preferences, sessions and security log | Each person’s own use of this site, not its content. |
| Site code, the page cache, the 404 log, AI activity, backups and their keys | This site’s own workings, not its content. |
| The discussion settings’ hold list and block list | Moderators can type IP addresses into them, and no IP address leaves the site. |
| Nothing is picked out of an item’s or a term’s fields, or out of any other setting’s value: each is written whole | None of them holds a secret or an IP address today: secrets are a setting type of their own, left out above, and no field type holds one. A field or setting that ever does will be left out by name, as the two lists are. |
