## CommentStatusChanged

A comment arrived, or its status changed: approved, held, marked as spam or trashed by a moderator, or posted as a reply from the admin. Never carries the comment's text or anything about who wrote it. Sent after the change is saved, never during an import run.

- **Class:** `Teme\Contracts\Comments\CommentStatusChanged`
- **Verb:** Notification
- **Capability:** `content.read`
- **Since:** 0.5.0

| Parameter | Description |
|---|---|
| `commentId` | the comment's ID |
| `item` | the item it is on |
| `from` | its status before, or null for a new comment. Today one of: pending, approved, spam or trash; later releases may add others, so a plugin treats a value it does not know as it would an unknown status, and never matches the list exhaustively. |
| `to` | its status now. Today one of: pending, approved, spam or trash; later releases may add others, so a plugin treats a value it does not know as it would an unknown status, and never matches the list exhaustively. |
| `actorId` | the account ID of the person who changed it, or null when no signed-in person did, such as a guest commenting |

- **Class:** `Teme\Contracts\Content\ContentSaved`

| `to` | its visibility now. Today one of: public, private or protected; later releases may add others, so a plugin treats a value it does not know as it would an unknown visibility |
| `formerUrl` | the live address it had, or null when it had none |
| `actorId` | the account ID of the person who changed it, or null when no signed-in person did |

## CollectPersonalDataHolders

Gathers the plugins' holders of personal data, asked at each step of a privacy request. A listener that fails stops the request, so an erasure is never reported done while a holder was missed. A preview until Teme 1.0 (I-3187).

- **Class:** `Teme\Contracts\Privacy\CollectPersonalDataHolders`
- **Verb:** Collect
- **Capability:** none
- **Since:** 0.5.0
