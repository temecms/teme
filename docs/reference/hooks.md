## PagesPurged

The public pages a change purged from the page cache, and the CDN purge queued for them. Sent once for each purge, after the change is saved and never inside its transaction, so a plugin can purge an outside cache of its own. Nothing is sent when the page cache is off. The tags are what a purge is made of, so purge an outside cache by tag. The addresses are only the cached pages core warms again, and are empty when warming is off, so never rely on them being complete.

- **Class:** `Teme\Contracts\Cache\PagesPurged`
- **Verb:** Notification
- **Capability:** `content.read`
- **Since:** 1.7.0

| Parameter | Description |
|---|---|
| `tags` | the cache tags the change purged, each once, sorted |
| `addresses` | the public addresses the purge touched, as absolute URLs, where core knows them |

| Parameter | Description |

## BeforeSave

An item is about to be saved: a new draft, a saved draft or a publish. It is asked before the Operation's transaction opens, so nothing has been written yet, and a listener that answers with a Veto stops the save and its reason is shown to the person. A listener that fails, or takes too long, lets the save through and is recorded as a fault.

- **Class:** `Teme\Contracts\Content\BeforeSave`
- **Verb:** Gate
- **Capability:** `content.read`
- **Since:** 1.8.0

| Parameter | Description |

| `language` | the item's language, or null for the site's default |
| `title` | the title as it would be saved |
| `document` | the document as it would be saved, as Tiptap JSON |
| `fields` |  |
| `actorId` | the account ID of the person saving it, or null when none |
