## Teme\Contracts\Hooks

### Collect

`Teme\Contracts\Hooks\Collect`, interface. Since 0.5.0.

A hook that gathers items from every listener. A listener is `fn (TheHook $hook): list<mixed>`; every good item is kept, in listener order, and a listener that fails or gives an item of the wrong type adds none of its items.

- `itemType(): string` — The PHP type each item must have: string, int, float, bool, array, list, or a class or interface, optionally prefixed with `?`. Since 0.5.0.

### Failure

`Teme\Contracts\Hooks\Failure`, enum. Since 0.5.0.

What a listener's failure does, declared by core on the hook, never by the plugin. Only a Transform or a Collect may fail the operation; a Notification goes on, a Gate refuses and a Resolve answers nothing.

- case `SkipListener` — The failing listener is skipped and the rest go on. Since 0.5.0.
- case `FailOperation` — The whole operation fails: for a check whose skipping would let it silently vanish. Since 0.5.0.

### Gate

`Teme\Contracts\Hooks\Gate`, interface. Since 0.5.0.

A hook that lets listeners refuse something before it happens. A listener is `fn (TheHook $hook): ?Veto`; the first Veto stops it, and a listener that fails refuses it too, to be safe.

### Hook

`Teme\Contracts\Hooks\Hook`, interface. Since 0.5.0.

What every hook is: a class that is its own name, its payload and its contract. A hook also implements exactly one of the five verbs, Notification, Transform, Gate, Resolve or Collect, which say how its listeners are called and what the dispatch gives back.

### HookContract

`Teme\Contracts\Hooks\HookContract`, class. Since 0.5.0.

The rules core declares on a hook's class: what a plugin must have been granted to listen, what a listener's failure does, and, for a hook being retired, when it stops being sent and what replaces it. The version a hook appeared in is its class docblock's `@since`.

- `__construct(?string $capability = null, Failure $failure = Failure::SkipListener, ?string $deprecated = null, ?string $removedIn = null, ?string $use = null)`. Since 0.5.0.

### HookRefused

`Teme\Contracts\Hooks\HookRefused`, class. Since 0.5.0.

Thrown when a plugin subscribes to something it may not: a class that isn't a hook, a hook its teme-plugin.json doesn't list, a hook whose capability it wasn't granted, or any hook once its register() is over.

### HookSender

`Teme\Contracts\Hooks\HookSender`, interface. Since 0.9.0.

Sends the calling plugin's own declared hooks to the plugins that listen: each a class in the plugin's own namespace, named in its manifest's `contributes.hooks`. Listeners are called as for Teme's own hooks: a listener's failure, the order and the failure rules are the same.

- `notify(Notification $hook): void` — Tells every listener; waits for the outermost commit when a transaction is open, as Teme's own notifications do, and is never told if it rolls back. Since 0.9.0.
- `transform(Transform $hook): mixed` — Returns the value as the last good listener left it. Since 0.9.0.
- `collect(Collect $hook): array` — Returns every good item, in listener order. Since 0.9.0.

### Hooks

`Teme\Contracts\Hooks\Hooks`, interface. Since 0.5.0.

How a plugin listens: each plugin gets its own, bound to its name, what it was granted and the hooks it declared, open only while its register() runs. A subscription is removed by its handle, never by its listener.

- `on(string $hook, callable $listener, ?Order $order = null): Subscription` — Subscribes a listener to a hook, heard from the next dispatch. Since 0.5.0.
- `off(Subscription $subscription): void` — Removes a subscription this plugin made, while register() runs; anything else is ignored. Since 0.5.0.

### Notification

`Teme\Contracts\Hooks\Notification`, interface. Since 0.5.0.

A hook that tells listeners what happened. A listener is `fn (TheHook $hook): void`; what it returns is ignored, and a listener that fails never stops the others.

### Order

`Teme\Contracts\Hooks\Order`, class. Since 0.5.0.

Where a listener runs among a hook's listeners: a stage, and the plugins it runs after or before inside that stage, by their Composer package names. Never a number. Each method gives a copy.

- `early(): self`. Since 0.5.0.
- `normal(): self` — The order a listener has when it is given none. Since 0.5.0.
- `late(): self`. Since 0.5.0.
- `after(string ...$plugins): self` — A copy that also runs after these plugins' listeners. Since 0.5.0.
- `before(string ...$plugins): self` — A copy that also runs before these plugins' listeners. Since 0.5.0.

### Resolve

`Teme\Contracts\Hooks\Resolve`, interface. Since 0.5.0.

A hook that asks listeners for one answer. A listener is `fn (TheHook $hook): mixed` and returns an answer or null; the first answer wins, and a listener that fails before one comes leaves none.

- `valueType(): string` — The PHP type the answer must have: string, int, float, bool, array, list, or a class or interface, optionally prefixed with `?`. Since 0.5.0.

### Stage

`Teme\Contracts\Hooks\Stage`, enum. Since 0.5.0.

The coarse place a listener takes among a hook's listeners: every early one runs before every normal one, and every normal one before every late one, whatever their plugins name.

- case `Early`. Since 0.5.0.
- case `Normal`. Since 0.5.0.
- case `Late`. Since 0.5.0.

### Subscription

`Teme\Contracts\Hooks\Subscription`, class. Since 0.5.0.

The handle a subscription gives back, and the only way to remove it. Its ID is `{plugin}#{hook's short name}#{n}`, n counting from 1 the plugin's subscriptions to that hook in the order they were made.

- `__construct(string $id)`. Since 0.5.0.

### Transform

`Teme\Contracts\Hooks\Transform`, interface. Since 0.5.0.

A hook that lets listeners change a value, one after another. A listener is `fn (mixed $value, TheHook $hook): mixed` and returns the next value; a value of the wrong type, or a listener that fails, keeps the value the one before gave.

- `valueType(): string` — The PHP type every value must have: string, int, float, bool, array, list, or a class or interface, optionally prefixed with `?`. Since 0.5.0.
- `value(): mixed` — The value before any listener changed it. Since 0.5.0.

### Veto

`Teme\Contracts\Hooks\Veto`, class. Since 0.5.0.

A gate listener's refusal, with one sentence saying why.

- `__construct(string $reason)`. Since 0.5.0.
